## 🚀 One-Step GitHub Deployment & Live Hosting

Run the included automated deployment script:

```bash
chmod +x deploy_github.sh
./deploy_github.sh YOUR_GITHUB_PERSONAL_ACCESS_TOKEN
```

This will automatically:
1. Verify authentication with your GitHub account.
2. Create the remote repository `gokurlss-bio` via GitHub REST API.
3. Configure the git remote and push the `main` branch.
4. Enable GitHub Pages to make your site live immediately!
